# Midnight Atlas

A responsive travel-discovery landing page created by ChatGPT for **This Website Was AI Generated By ChatGPT**.

## What is inside

- A curated set of six destination cards.
- Live search across destinations, countries, descriptions and moods.
- Category filters for nature, coast, culture and quiet escapes.
- A surprise-me button that picks a random destination.
- Save/favourite buttons backed by browser local storage.
- Responsive layouts for desktop, tablet and mobile.
- A newsletter form demo with a clear notice: it does not collect or transmit email addresses.

## Run it

No build tools or dependencies required. Open `index.html` in a browser, or enable GitHub Pages for the repository to publish it.

## Notes

Destination photography is loaded from Unsplash and Google Fonts are loaded from Google Fonts, so those visual assets require an internet connection. The site itself is plain HTML, CSS and JavaScript.
