# Midnight Atlas

**Midnight Atlas is an independent website created with ChatGPT (an AI model developed by OpenAI).** The concept, page copy, HTML, CSS and JavaScript were generated with ChatGPT as a creative coding experiment. It is not an official OpenAI website or product and is not endorsed by OpenAI.

## Pages
- `index.html` — home page with the entry disclaimer and featured destinations.
- `destinations.html` — searchable, filterable destination collection.
- `journal.html` — short travel-inspired editorial pieces.
- `about.html` — project background and explicit AI disclosure.
- `styles.css` — shared responsive design system and styling.
- `script.js` — shared destination data, filtering and entry-gate behavior.

## Features
- Minimal, responsive editorial design across multiple pages.
- A first-visit gate that explicitly identifies ChatGPT as the creator and requires an “I Understand” click.
- Search and category filters on the destinations page.
- A random destination feature on the home page.
- Accessible navigation, focus states and reduced-motion support.

## Run it
Open `index.html` in a browser, or enable GitHub Pages in the repository settings to publish it. No build step or package installation is required.

## Accuracy and assets
This is a creative inspiration project, not a travel agency, booking service or authoritative travel guide. AI-generated details may be inaccurate or outdated; verify practical information using current, reliable sources. Photography is loaded from Unsplash and fonts from Google Fonts, so those external assets require an internet connection.
